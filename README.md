# Motif Productivity Suite

Motif Productivity Suite is a productivity dashboard for tracking projects, tasks, and delivery progress in a single workspace.

## Project Highlights

- Modern React + TypeScript application architecture
- Vite-powered development workflow with production builds
- Task and project management views with local workspace persistence
- Dashboard analytics for delivery progress and recent activity
- Type-checking, linting, and CSS validation built into the workflow

## Available Scripts

```bash
npm install
npm run dev
npm run build
npm run test
npm run lint
```

## Workflow Notes

- `npm run dev` starts the local Vite development server
- `npm run build` produces the production bundle
- `npm run test` runs the app smoke tests
- `npm run lint` validates the TypeScript, JavaScript, CSS, and workspace styling rules

This project is intended to feel like a real product surface rather than a generic starter template, and it is designed to support ongoing feature work and product iteration.
